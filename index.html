物語は、駅から駅へ

ひとつの章が終わるたび、星の軌道に新しい線路が伸びていく。仲間と出会い、街の人を助け、星の神々の秘密に近づく旅。物語は章をまたいでずっと続いていきます。

第一章

旅のはじまり

列車に乗りこみ、はじめての街と仲間に出会う。

第二章

星を呼ぶ者

砂漠、空島、氷の地、そして海。星祭りの夜にたどり着くまでの大冒険。

第三章　制作中

終着駅の先へ

列車がはじめて止まる、まだ誰も知らない大陸。これまでで最大の舞台。

Aeon's Path でできること

手ごたえのあるアクション戦闘

金色の光を待って放つ会心の一撃、攻撃を受け流すパリィ。ボスの予兆を見切って戦います。

道ごとに違うスキル

運命の行人や司令など、選んだ道によって戦い方ががらりと変わります。

遺物を集めて強くなる

星の数でランクが決まる遺物。組み合わせ次第で、自分だけの戦い方に。

再戦の門

倒したボスに何度でも。難易度は5段階、上げるほど報酬と遺物が良くなります。

街の依頼と掲示板

街の人からの頼みごとをこなして、お金や素材、経験値を手に入れます。

遊戯場でひと休み

目押しができるスロットやパチンコ台。ゲーム内のお金だけで遊べます。

セーブデータ3つ

ひとりで3人分の旅を。切り替えは旅の列車の中から。

4つの言語に対応

日本語・English・한국어・简体中文で遊べます。

遊び方

Aeon's Path は専用サーバーで遊ぶ形です。参加は無料。サーバーのアドレスはリリースが近づいたらお知らせします。

PC・スマホ

  1. マインクラフト統合版を最新にする
  2. 「遊ぶ」→「サーバー」→「サーバーを追加」
  3. お知らせするアドレスとポートを入力して参加

Switch・PS4/PS5・Xbox

  1. 各機種のオンラインサービスに加入しておく
  2. ゲーム機には「サーバー追加」がないため、専用の入り方を用意します
  3. 手順はリリース前にこのページとDiscordで公開します

よくある質問

無料で遊べますか？

はい、無料です。ゲーム機でのオンラインプレイには、各機種のオンライン加入サービスが必要な場合があります。

自分のワールドで遊べますか？

Aeon's Path はサーバーでのみ遊べる形にしています。アドオンの配布は行っていません。

課金要素はありますか？

現在、課金要素はありません。

友達と一緒に遊べますか？

はい。同じサーバーで一緒に冒険できます。

事前登録をするとどうなりますか？

リリースのお知らせや参加方法をいち早くお届けします。登録者が多い場合は、参加の順番を抽選で決めることがあります。

バグを見つけたら？

Discordの報告チャンネルに、起きたこと・場所・機種を添えてお知らせください。

案内役 ジャービス

分からないことがあれば、ジャービスが丁寧にお答えします。Discordとこのページから話しかけられるよう、ただいま準備中です。

サーバーにはどうやって入るの？
ジャービスご参加ありがとうございます。お使いの機種によって入り方が異なりますので、「Switchの入り方」のように機種名を添えてお尋ねください。
